# iPhone feature comparison

Checked on November 19, 2026 against the iPhone listing for version 1.2.1, all ten publisher screenshots, and the publisher’s support and privacy pages. The entries describe the behavior users can inspect in this free project. Private implementation details and screens absent from those sources remain unverified. [Reference App Store listing](https://apps.apple.com/us/app/monero-wallet-xmr/id6814596825) · [Reference support](https://monerowallet.app/support) · [Reference privacy policy](https://monerowallet.app/privacy) · [Screenshots in Apple’s catalog](https://itunes.apple.com/lookup?id=6814596825&country=us)

| Feature | Where to use it in this app | Implementation and checks |
| --- | --- | --- |
| Create a self-custody wallet | Welcome → Create wallet | Native wallet2 creates a classic 25-word wallet locally. Two randomly chosen words must match the written backup before first entry. |
| Keep separate wallets | Overview → wallet name → Add a wallet | Each wallet has a separate encrypted file, password, primary address, balances, history, contacts and invoice records. Switching invalidates the previous session. The picker shows the current balance and synchronization status, and shows another wallet’s recovery format and restore height when recorded. |
| Restore by words or keys | Restore wallet → recovery method | Supports classic 25-word seeds with optional offsets, 13-word MyMonero across its supported dictionaries, 16-word Polyseed, supported BIP39, private spend/view keys, and address plus private view key. The result shows the primary address for confirmation. [Exact formats and migration details](../Recovery/README.md) |
| Receive and share a QR | Overview → Receive → New subaddress | Choose a primary or labeled address. Enter an optional amount to update the payment URI in the QR and share sheet. The copy control copies the plain address. |
| Send Monero | Overview → Send or Scan | Accepts pasted addresses, contacts, camera scans and a QR in a single selected photo. Check the address and optional request amount, choose a fee priority and attach a local note. Max sweeps all eligible inputs after fees. The single-subaddress option tries funded sources in random order and reports when the reviewed transfer combines multiple subaddresses. Swipe and authenticate to send. View-only wallets can export the unsigned payment. |
| Balances and history | Overview and Activity → select a payment | Native balances distinguish unlocked and locked funds. Filter incoming and outgoing transfers, see exact XMR totals and counts, and search hashes, notes and recipient addresses or contacts. Day-grouped history and transfer details show notes, confirmations, fees and optional current USD estimates. |
| Automatic nodes and failover | Tap the node in the header → Public nodes | Concurrent health probes select the fastest available healthy response on the chosen route. Tor probes go through the active local SOCKS proxy. A stalled scan or lost connection triggers another candidate. The direct directory has 50 named HTTPS endpoints, and the Tor directory has ten v3 onion endpoints. Search, test response times and pin one entry or allow failover. Rescan from the wallet’s restore height. The dashboard shows current and target heights. |
| Custom node and Tor | Node and sync settings → My node or Route through Tor | Use your own HTTPS daemon, an on-device daemon, or a v3 onion node. Tor can bootstrap inside the app. An existing local SOCKS proxy is also supported. [Transport and privacy](../SECURITY.md) |
| Keep awake and Lock Screen progress | Settings → Synchronization | Opt into keeping the display on during scans or viewing heights in a Live Activity. The app locks and runs a restricted scan during available iOS background time. The activity displays a paused state when the scan stops. |
| Coin control | Wallet → Tools → Coin control, or Send → inputs | See individual unspent outputs, label, freeze or thaw them. The transaction builder accepts selected key images and the corresponding source subaddresses. |
| Cold signing | Wallet → Tools → Cold signing and Restore wallet → View only | Pair using address and view key, move outputs and signed key images, review the unsigned transaction on the offline signer, and broadcast the signed result from the online wallet. Uses wallet2 multipart UR. [Isolated payment test](Regtest.md) |
| Invoices | Store → New request, or Wallet → Tools → Payment requests | Create a dedicated subaddress and a QR with the requested amount. Its incoming funds determine awaiting, partially paid and paid status. Spending a receipt keeps the amount received on that invoice. |
| Privacy Pulse | Wallet → Tools → Privacy Pulse, or Settings → Privacy | The five checks deduct 8 points for an unset app lock, 3 for disabled biometrics, 5 for the node choice, 7 for an unverified recovery backup and 10 for the invoice subaddress check. Protocol protections have their own descriptions. The score reflects local observations. It cannot measure a user’s anonymity. |
| Contacts | Wallet → Tools → Contacts, or Send → Contacts | Save and remove local address-book entries, choose a recipient and initiate a payment. |
| Live price chart | Market, or Overview → XMR / USD | On a direct online route, opt into CoinGecko quotes for the open wallet session. View USD estimates and 24-hour movement from Overview, USD equivalents during a payment, and a refreshable chart across four time ranges. |
| Interface languages | Welcome → globe or Settings → Language | Ships 23 languages, including all languages named on the reference listing. Arabic uses a right-to-left layout and confirmation gesture. The catalog flags machine-assisted translations for human review. [Language coverage](../Localization/README.md) |
| Appearance | Settings → Appearance | Select light, dark or system appearance, including sheets and security controls. |
| PIN and Face ID | During setup and Settings → Wallet security | The PIN protects the wallet unlock key. Users can enroll biometrics, change their PIN, and reset it using the device passcode. Backgrounding locks the wallet. |
| Encrypted recovery backup | Settings → View recovery backup | Fresh authentication reveals the original recovery material for new imports. Older wallet files expose their native backup material. A fresh authentication and explicit confirmation allow a local-only, expiring clipboard copy of a recovery phrase. Seed passphrases must be retained separately. |
| Delete all data | Settings or the locked screen → erase all → type DELETE | The app authenticates, clears wallet files, recovery credentials, Tor state and preferences, and can resume an interrupted full erase. |

For the distinction between features implemented, checks run with disposable wallets and release work that needs physical iPhones, see [verification results](Verification.md).

## Observable differences

The reference setup screenshot offers a four-to-six-digit PIN and a skip button. This app requires a six-to-twelve-digit PIN. The reference node screenshot shows 50 entries. This app ships 50 HTTPS endpoints, ten additional v3 onion endpoints, and supports custom nodes. The reference privacy policy allows price traffic to go directly to CoinGecko when Tor is active. This app disables price traffic on Tor and offline routes, and asks for opt-in on direct routes. The Home and Activity screenshots show Wallet, Activity, Market, Store and Settings in that order. This app offers those five destinations. The reference listing documents invoice creation, dedicated subaddresses and payment status. None of its ten screenshots shows Store open, and its public support page does not identify Store’s contents. Placing the invoicing workflow under Store is this project’s design choice. Any other Store functionality remains unverified.
